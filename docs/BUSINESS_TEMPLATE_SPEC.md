# Business Template Specification

A business archetype translates industry psychology into a reusable site architecture. It is not a visual skin.

## Required model

Each archetype defines:

- stable `id` and semantic version;
- parent industry;
- primary business goal;
- audience intent and trust model;
- proof mechanism;
- conversion model;
- UX recipe;
- Design DNA references;
- reusable pattern references;
- page set;
- motion and content-density intent;
- RTL/LTR support;
- accessibility target.

## Differentiation gate

Two archetypes in one industry are considered distinct only when at least two dimensions differ materially: UX flow, page/layout architecture, proof mechanism, conversion model, motion model, content density, interaction model, Design DNA or pattern composition.

Changing only color, font, imagery or wording never creates a new archetype.

## Business psychology

Default examples:

- Architecture: Emotion → Philosophy → Portfolio → Process → Proof → Enquiry.
- Legal: Problem → Authority → Expertise → Evidence → Process → Consultation.
- Cafe/Restaurant: Atmosphere → Menu → Signature Items → Social Proof → Location → Reservation.
- Professional Services: Problem → Outcome → Capability → Proof → Method → Contact.

The catalog may evolve these flows per archetype while preserving the underlying business intent.
