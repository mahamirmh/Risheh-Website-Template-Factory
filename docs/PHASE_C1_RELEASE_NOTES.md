# Phase C1 Release Notes

Phase C1 introduces the first executable product surface for Risheh Website Template Factory.

## Added
- Next.js 16.3 / React 19.3 application shell.
- Guided visual composition flow for business, industry, archetype, Design DNA, pages, patterns, brand/content and quality preferences.
- Direct server-side consumption of Phase B source catalogs.
- Deterministic `risheh.build-spec.v1` composition engine.
- AJV schema validation endpoint.
- JSON/YAML import and export.
- Versioned browser draft persistence.
- Codex, Claude Code and generic agent handoff generation.
- Responsive desktop/mobile generator UI with RTL/LTR support.
- C1 contract tests and production Next.js build in CI.

## Out of scope
- autonomous code generation;
- deployment;
- authentication;
- cloud persistence;
- CMS provisioning;
- billing;
- external AI provider calls.

These remain outside C1 and preserve a clean Phase C2 boundary.
