# C2 Agent Enhancement Policy

Agent enhancement is optional. The deterministic generator must already produce a runnable project before any agent is allowed to modify it.

## Allowed

- visual polish consistent with resolved Design DNA;
- responsive composition improvements;
- component-internal refactors with unchanged behavior;
- non-factual microcopy;
- accessibility and semantic markup improvements;
- replacement of neutral structural copy only when factual user content already exists.

## Forbidden

- changing routes or Build Spec schema identity;
- changing industry, archetype, or Design DNA identity;
- inventing testimonials, metrics, awards, customers, prices, credentials, addresses, outcomes, team members, or inventory;
- replacing the dependency baseline without explicit approval;
- weakening accessibility safeguards;
- manually rewriting provenance claims;
- copying reference-site trade dress.

The agent handoff is generated by `src/features/codegen/agent-policy.ts`. After an enhancement pass, the full generated-project quality pipeline must run again.
